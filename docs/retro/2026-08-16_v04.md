- 받아쓰기 요금과 저장 용량을 **실제로 재서** 문서에 적었습니다

v03에서 「녹음해서 받아쓰기」를 만들어 배포했고, 사용자가 폰에서 눌러 보셨습니다.

```
● 듣 는 중  🎧녹음  [잠깐] [끝내기]     ← 「듣는 중」이 세로로 쪼개지고

```

**두 번째가 더 나빴습니다.** `429` 라는 숫자만으로는 기다릴 일인지, 돈을 내야 할 일인지,
제가 뭘 잘못 만든 것인지 **아무도 알 수 없었습니다.**

## 🛠 작업 상세

### 1. 시간이 버튼에 가리지 않게

- **무엇을:** 좁은 화면에서는 **버튼을 통째로 아랫줄로** 내렸습니다. 시간은 굵게 키웠습니다.
- **왜:** 회의 중에 제일 자주 보는 숫자가 **몇 분째인가**입니다. 그게 버튼에 가려 있었습니다.
  v02에서 화면을 고칠 때 이 줄은 「글자 몇 개 + 버튼 두 개」라 괜찮을 줄 알았는데,
  방식 표시(🎧 녹음)가 v03에서 하나 더 붙으면서 넘쳤습니다.
- **결과:** 폰에서 시간이 항상 보입니다.

### 2. 거절 이유를 갈라서 우리말로

- **무엇을:** AI가 거절했을 때 **왜 거절했는지를 나눠 말해 주는 장치**를 만들어,
  받아쓰기와 클로니 **양쪽에 같이** 붙였습니다.

  | 뜬 말 | 사용자가 할 일 |
  |---|---|
  | 요청이 몰려 잠시 거절됐습니다 | **아무것도** — 스스로 두 번 더 시도합니다 |
  | AI 크레딧 잔액이 없습니다 | 충전 |
  | AI 열쇠가 거부됐습니다 | 열쇠 다시 등록 |
  | 이 계정에서 못 쓰는 모델입니다 | 모델·등급 확인 |

  그리고 **AI가 보낸 원문 설명을 그대로 덧붙입니다.** 우리가 요약하면 단서가 지워집니다.

- **왜:** 아래 이슈 1번이 그대로 이유입니다.
- **결과:** 다음에 막히면 **화면만 보고 무엇을 할지 압니다.** 실제로 이 장치를 붙이자마자
  원인이 30초 만에 나왔습니다.

### 3. 요금과 용량을 실제로 재서 적었습니다

- **무엇을:** 받아쓰기 단가(분당 $0.006)와 저장 용량(DB 12MB / 500MB 사용 중)을
  직접 확인해 설계서와 확인메모에 적었습니다.
- **왜:** *"소리 길이만큼 요금"* 이라고만 적어 두면 **얼마인지 감이 안 옵니다.**
  설계서에는 「금액을 적지 않는다」는 원칙이 있는데, **시간으로 매기는 요금은 예외로 뒀습니다** —
  토큰과 달리 사용자가 스스로 계산할 방법이 없습니다. 대신 **확인한 날짜와 모델명**을 같이 적었습니다.
- **결과:** 1시간 회의 약 610원, 월 5,000원 안쪽. 저장은 1시간 회의 8,000건분이 남아 있습니다.
  **녹음 파일을 저장하지 않기 때문**입니다 — 파일로 남겼으면 1GB가 20시간 만에 찹니다.

## 😵 어려웠던 점 & 해결

### 🔴 1. 숫자 하나가 세 가지를 뜻하고 있었습니다

- **상황:** 폰에서 받아쓰기를 눌렀더니 *"받아쓰기에 실패했습니다 (429)"* 가 떴습니다.
- **증상:** 그 문장으로는 **아무것도 알 수 없었습니다.** 사용자는 *"OpenAI 잔액이 남아 있는데?"*
  라고 하셨고, 저는 저대로 짐작만 늘어놓았습니다.
- **원인:** `429` 라는 한 숫자에 **완전히 다른 세 가지**가 들어 있습니다 —
  ① 잠깐 몰림(기다리면 됨) ② 돈이 떨어짐(충전해야 함) ③ 못 쓰는 모델(등급 문제).
  더 나쁜 것은, **AI가 보낸 설명 원문을 제가 버리고 숫자만 화면에 올렸다는 점**입니다.
  거기에 답이 그대로 적혀 있었는데 사용자에게 안 보여 준 것입니다.
- **해결:** 이유를 가르는 장치를 만들고, **원문을 함께 보여 주게** 했습니다. 그러자 바로 나왔습니다 —
  `"You have no credits remaining"`, `code: credit_balance_exhausted`.
- **남은 문제:** 오류를 「사용자에게 친절하게 요약」하려다 **단서를 지우는 것**은 어디서든 납니다.
  이번엔 *"짧게 쓰되 원문은 붙인다"* 로 정했지만, 다른 자리에도 같은 실수가 있을 수 있습니다.

### 🔴 2. 「한도」와 「잔액」을 헷갈렸습니다 — 저도, 사용자도

- **상황:** 사용자가 OpenAI 사용량 화면을 보여 주셨습니다. `$2.54 / $10.00` 이 찍혀 있었습니다.
- **증상:** 그걸 보고 *"잔액이 남아 있는데 왜 막히지"* 가 됐습니다.
- **원인:** 그 숫자는 **「이번 달에 10달러까지만 쓰겠다」는 내가 정한 상한**이지 **남은 돈**이 아닙니다.

  ```
  한도(Limit)     = 과속 방지턱 — 내가 얼마까지 쓸지 정한 것
  잔액(Balance)   = 기름        — 실제로 남은 돈      ← 이게 0이었다
  ```

  **두 숫자가 서로 다른 화면에 있어서** 사용자가 「한도」 화면만 보고 잔액이라고 읽으신 것입니다.
- **해결:** 오류 문구에 **그 구분을 통째로 적었습니다** —
  *"「이번 달 한도」가 아니라 충전해 둔 잔액을 확인해 주세요. 한도가 남아 있어도 잔액이 0이면 거절됩니다."*
  헷갈릴 수 있는 것은 헷갈리지 말라고 **그 자리에** 적어야 합니다.
- **남은 문제:** ⚠️ **충전이 아직 안 됐습니다.** 카드가 거절당하고 있습니다
  (구독은 되는데 API 결제만 막힘 — 카드사 쪽 문제로 보입니다).
  **기능은 다 준비돼 있고 크레딧만 채우면 도는 상태**입니다.

### 🟡 3. 화면을 고칠 때마다 그 줄에 뭔가 하나씩 붙었습니다

- **상황:** v02에서 상태 줄을 폰에 맞춰 고쳤는데, v03에서 그 줄에 「🎧 녹음」 표시가 붙었습니다.
- **증상:** 넘쳐서 시간이 가려졌습니다.
- **원인:** *"지금은 들어간다"* 를 기준으로 맞췄기 때문입니다. **한 줄에 밀어 넣는 배치는
  항목이 하나만 늘어도 깨집니다.**
- **해결:** 넘치면 **줄을 나누게** 했습니다. 글자를 쪼개는 대신 줄을 넘깁니다.
- **남은 문제:** 없음. 다만 「지금 화면에서 잘 보인다」는 다음 기능이 붙으면 무너집니다.

## 🔀 갈림길에서 무엇을 왜 골랐나

### 오류 메시지를 얼마나 자세히 보여줄까

| | |
|---|---|
| **고른 것** | **우리말 한 줄 + AI가 보낸 원문** |
| 버린 것 | ① 숫자만 (지금까지) ② 우리말로만 요약 |
| **결정적 이유** | ②로 하면 이번 일이 또 납니다. 요약은 **아는 원인만** 담을 수 있는데, 모르는 원인이 오면 지워집니다. 원문이 붙어 있으면 **제가 예상 못 한 이유도 사용자가 읽어서 알려 줄 수 있습니다** |
| **치른 대가** | 오류 문구가 길어지고 영어가 섞입니다. 다만 오류는 **자주 보는 화면이 아닙니다** |

### 시간으로 매기는 요금을 설계서에 적을까

설계서 §8.2에는 **「금액을 적지 않는다」**는 원칙이 있습니다(단가가 자주 바뀌어서).
이번엔 **예외로 적었습니다.** 토큰 요금은 표에 사용량이 있어서 곱하면 되지만,
**시간 요금은 사용자가 계산할 방법이 없습니다.** 대신 **확인 날짜와 모델명**을 같이 적어,
언제 기준인지 알 수 있게 했습니다.
