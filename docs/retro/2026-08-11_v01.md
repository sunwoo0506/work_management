## 🛠 작업 상세

### 1. 인박스를 맨 위로

- **무엇을:** 떠오른 것을 아무렇게나 던져두는 「인박스」를 업무 화면 맨 아래에서
  맨 위로 옮겼습니다.
- **왜:** 인박스는 **마찰이 0에 가까워야 하는 칸**입니다. 회의 중에 뭔가 떠올랐을 때
  스크롤을 내려서 찾아야 하면 그냥 안 적습니다. 안 적으면 인박스가 있으나 마나입니다.
- **결과:** 화면을 열면 바로 손이 닿습니다. 적고 엔터 한 번이면 들어갑니다.

### 2. 첫 화면을 「진행중」으로

- **무엇을:** 업무 화면을 처음 열면 「전체」가 아니라 **「진행중」만** 보입니다.
- **왜:** 지시사항 13건 아래에 업무 46건을 넣어 뒀는데, 그게 전부 한 화면에
  줄줄이 나오니 벽처럼 보였습니다. 정작 지금 붙잡고 있는 건 두세 건인데요.
- **결과:** 열면 지금 하는 일만 보입니다. 「진행중」이 비어 있으면
  *"업무 46건이 다른 상태에 있습니다. 「전체」를 눌러 보세요"* 라고 알려 줍니다
  — 빈 화면만 보고 "고장났나" 하지 않게.

### 3. 전체 목록을 영역별로 접었다 폈다

- **무엇을:** 「전체」를 누르면 업무가 **영역별로 묶여서** 나옵니다
  (회생지원 · 인수인계 · 재고 · 회계·세무 …). 각 묶음은 제목 줄을 눌러 접었다 폈다 합니다.
- **왜:** 사용자가 *"섹션만 나눌지 토글까지 적용할지 니가 판단해봐"* 라고 하셨습니다.
  **나누기만 하면 줄 수가 그대로입니다.** 46줄이 11묶음으로 나뉜 46줄이 될 뿐이라
  "복잡해 보인다"가 안 풀립니다.
- **결과:** 접어야 화면이 실제로 짧아집니다. 다만 **전부 접지는 않았습니다** —
  다 접혀 있으면 오늘 볼 것을 보려고 매번 눌러야 하니까요.

```
지연이나 오늘 마감이 있는 영역  →  펴 둡니다    (그냥 보입니다)
나머지 영역                     →  접어 둡니다   (제목 줄만)
```

  묶음 **순서도 급한 것이 위**입니다. 가나다순이면 오늘 터질 일이 맨 아래로 갑니다.
  접혀 있어도 제목 줄에 `지연 3` `오늘 1` 이 붙어서 안 열어도 압니다.

### 4. 오늘 마감 눈에 띄게 — 색을 안 늘리고

- **무엇을:** 오늘이 기한인 업무는 줄 배경이 밝아지고, 왼쪽에 검은 기둥이 서고,
  제목이 굵어지고, 「오늘 마감」 배지에 테두리가 생깁니다.
- **왜:** 아래 이슈 2번 참고. 색을 하나 더 만들면 안 되는 상황이었습니다.
- **결과:** 목록을 훑을 때 눈이 그 줄에서 걸립니다. 칸반 카드도 같은 규칙입니다.
  화면 위쪽에 「오늘 마감 3」 배지도 붙습니다.

### 5. 「여기엔 뭘 적나」 안내

- **무엇을:** 「상세」·「작업 메모」·「회신」 세 칸에 **무엇을 적는 칸인지** 설명을 붙였습니다.
  칸 이름 옆에 한 줄 요약이 있고, 「뭘 적나?」를 누르면 네댓 줄이 펼쳐집니다.
- **왜:** 사용자 말 그대로 — *"안 그러면 중복돼서 사용할 듯"*. 빈 칸 세 개가 나란히
  있으면 사람은 아무 데나 적습니다. 그러면 3개월 뒤에 같은 내용이 세 군데 나뉘어 있고
  어느 게 최신인지 모릅니다.
- **결과:** 세 칸이 갈립니다.

```
상세      이 일이 무엇인가        시작하기 전에 한 번
작업 메모  하면서 알게 된 것       일하는 중에 그때그때
회신      상대에게 뭐라고 답했나   닫기 직전에
```

  각 안내에 **「이건 여기 말고 저기」를 꼭 한 줄** 넣었습니다. 무엇을 적는지보다
  무엇을 **안** 적는지가 칸을 구분해 줍니다.

  **칸이 비어 있으면 안내가 저절로 펼쳐집니다.** 이미 적어 둔 사람에게는 방해니까요.

- **한 가지 더:** 「상세」와 「회신」도 이제 **업무 서랍에서 바로** 쓸 수 있습니다.
  전에는 「작업 메모」만 바로 쓸 수 있고 나머지는 수정 화면을 열어 열두 칸을 지나가야 했습니다.

### 6. 체크리스트 고치기 + 진행률 자동

- **무엇을:** 체크리스트 항목의 글귀를 **눌러서 그 자리에서** 고칩니다.
  그리고 체크한 개수가 곧 **진행률**입니다.
- **왜:** 전엔 오타 하나 고치려면 지웠다 다시 만들어야 했고, 그러면 체크해 둔 것이
  날아갔습니다. 진행률은 손으로 끄는 막대였는데, 그 숫자는 **아무 근거가 없습니다.**
  "70%"가 무슨 뜻인지 본인도 3일 뒤엔 모릅니다.
- **결과:** 「5개 중 3개 · 60%」처럼 나옵니다. 뒤에 사실이 남습니다.
  항목을 지워도 분모가 바뀌니 다시 계산합니다.

  **체크리스트가 있으면 진행률 막대를 아예 못 끌게 잠갔습니다.** 둘 다 열어 두면
  어느 쪽이 맞는지 알 수 없습니다. 체크리스트가 하나도 없는 업무는 예전처럼 손으로 끕니다.

### 7. 파일 올리기

- **무엇을:** 업무에 파일을 붙입니다. 끌어다 놓아도 되고 한 개 25MB까지입니다.
- **왜:** AI에게 *"이 공문 읽고 할 일 뽑아줘"* 를 시키려면 파일이 있어야 합니다.
- **결과:** 올리는 **그 순간 브라우저가 글을 뽑아 둡니다.** 그래야 나중에 물을 때마다
  파일을 다시 뜯지 않습니다(PDF 한 장 뜯는 데 몇 초 걸립니다).

  **글을 뽑는 일을 브라우저에서 하는 게 중요합니다.** 서버에서 뽑으려면 파일을
  서버로 보내야 하고, 그러면 계약서·급여대장이 한 번 더 밖으로 나갑니다.
  브라우저에서 뽑으면 **AI에게 보내기로 한 것만** 밖으로 나갑니다.

| 읽습니다 | 못 읽습니다 |
|---|---|
| PDF (쪽 번호까지 붙여서) | 한글 `.hwp` / `.hwpx` |
| 워드 `.docx` | 엑셀 `.xlsx` |
| `.txt` · `.csv` · `.md` · `.json` | 스캔한 그림 PDF · 사진 속 글자 |

  **못 읽는 파일도 보관은 됩니다.** 목록에 왜 못 읽었는지 그 자리에 뜹니다.

### 8. AI 업무 지원

- **무엇을:** 업무 서랍 안에 AI 칸을 넣었습니다. 두 가지를 합니다 —
  **① 파일을 읽고 체크리스트 초안을 뽑기 ② 일하다 모르는 것 묻기.**
  사용자가 말한 용도 그대로입니다.
- **왜:** 원래 3단계(AI)는 두 가지가 안 정해져서 멈춰 있었습니다. 그중 하나(모델 선정)를
  **임시로 정하고 진행**했습니다. 모델명이 코드에 안 박혀 있어서 나중에 바꿔도
  코드를 안 고칩니다.
- **결과:** 체크리스트 초안은 **담기 버튼을 눌러야** 들어갑니다. 저절로 안 들어갑니다.
  각 항목에 **근거**가 붙어 나옵니다 — *"근거: 공문 3쪽 제출서류 항목"*.
  질문 답변에도 **어느 자료를 봤는지**가 붙습니다.

  **지금은 열쇠(API 키)가 없어서 누르면 안내만 뜹니다.** 열쇠 한 줄만 넣으면
  그 자리에서 동작합니다. 확인 메모 C-10에 방법을 적었습니다.

## 😵 어려웠던 점 & 해결

### 🔴 1. 업무를 지우면 올린 파일이 저장소에 그대로 남습니다

- **상황:** 파일 올리기를 다 만들고 나서, 업무 삭제 화면을 다시 봤습니다.
- **증상:** 업무를 지우면 **"어느 파일이 붙어 있었나"라는 기록은 지워지는데
  파일 실물은 안 지워집니다.** 화면에서는 깨끗하게 사라진 것처럼 보입니다.
- **원인:** 파일 실물과 그 기록이 **다른 곳에 삽니다.** 기록은 데이터베이스에,
  실물은 별도 보관소에 있습니다. 데이터베이스는 "업무가 사라지면 딸린 것도 지워라"를
  자동으로 하지만, 그 규칙이 **보관소까지는 안 닿습니다.**
  구조를 짤 때 "표만 만들면 되겠지" 하고 넘어간 자리였습니다.
- **해결:** 업무를 지우기 **전에** 붙어 있던 파일 실물을 먼저 치우게 했습니다.
  같은 이유로 **AI 대화도 함께 지웁니다** — 스키마상 대화는 업무와의 연결만 끊기고
  살아남게 되어 있었는데, 없어진 업무에 대한 대화가 떠도는 건, 그것도
  **가장 사적인 기록**이 떠도는 건 좋지 않습니다.
  치우기가 실패해도 업무 삭제는 진행합니다. 사용자가 「지웁니다」를 눌렀는데
  곁다리 정리 실패로 안 지워지면 그게 더 이상합니다.
- **남은 문제:** ⚠️ **오늘 이전에 만들어진 것에는 해당 없습니다** (파일 기능이 오늘 생겼으니).
  하지만 같은 구조의 함정이 또 있습니다 — 앞으로 「보관소」에 뭔가를 더 넣게 되면
  (예: 회의 녹음) **삭제할 때 같이 치우는 것을 매번 손으로 챙겨야 합니다.**
  자동으로 안 됩니다.

### 🔴 2. "오늘 마감을 눈에 띄게" — 그런데 쓸 색이 없었습니다

- **상황:** *"업무 목록 중에서 오늘 마감인 것들은 하이라이트를 주면 좋겠다"* 를 만들려 했습니다.
- **증상:** 색을 고르려는데 **쓸 수 있는 색이 하나도 없었습니다.**

| 색 | 이미 쓰는 뜻 | 오늘 마감에 쓰면 |
|---|---|---|
| 파란색 | 누를 수 있는 것 | 눌러야 하는 줄 알게 됩니다 |
| 빨간색 | **기한 초과** | **진짜 지연된 건이 안 보이게 됩니다** |
| 주황색 등 | (금지) | 작업 규칙 위반 |

- **원인:** 작업 규칙(`CLAUDE.md`)에 *"파란색이 유일한 강조색이다. 두 번째 강조색을
  만들지 않는다"* 가 있습니다. 예외는 기한 초과 빨간색 하나뿐입니다.
  이건 **좋은 규칙입니다** — 색이 늘어나면 강조가 흐려집니다. 실제로 빨간색을
  오늘 마감에도 쓰면, 사흘 지난 건과 오늘 건이 같아 보입니다.
- **해결:** **색 말고 다른 것으로 세웠습니다.**
  줄 배경을 한 단계 밝게 + 왼쪽에 잉크색 기둥 + 제목 굵게 + 배지에 테두리.
  네 가지가 겹치니 색 없이도 눈이 걸립니다.
  이건 앞선 고민(확인 메모 C-07, 회생 건을 주황색으로 할까)과 **같은 문제이고
  같은 답**입니다 — "색이 아니라 표시와 굵기로".
- **남은 문제:** ⚠️ **약할 수 있습니다.** 색만큼 확 튀지는 않습니다.
  실제로 보시고 판단하셔야 합니다. C-07과 묶어서 한 번에 정하는 게 좋겠습니다.

### 🟡 3. AI에게 넘길 자료를 어디서 모을 것인가

- **상황:** AI에게 "이 업무의 상세·메모·체크리스트·첨부파일"을 보여 줘야 답을 합니다.
  그걸 **브라우저가 모아서 보낼지, 서버가 다시 읽을지** 정해야 했습니다.
- **증상:** 브라우저가 모아 보내는 쪽이 훨씬 간단합니다. 이미 화면에 다 있으니까요.
- **원인:** 그런데 그러면 **서버가 브라우저 말을 그대로 믿게 됩니다.**
  주소창을 열 줄 아는 사람이면 "이건 내 업무야" 하면서 아무 내용이나 밀어 넣을 수 있습니다.
- **해결:** **서버가 데이터베이스를 다시 읽습니다.** 브라우저는 "몇 번 업무"인지만 보냅니다.
  읽을 때 **호출한 사람의 로그인 표를 그대로 써서** 읽으므로, 남의 업무는 애초에 안 읽힙니다
  (남의 데이터를 막는 장치가 그대로 걸립니다).
- **남은 문제:** 서버가 한 번 더 읽으니 **답이 조금 느려집니다.** 대신 안전합니다.
  그리고 첨부파일 글을 데이터베이스에 저장해 두기 때문에 파일을 다시 내려받지는 않습니다.

### 🟡 4. 열쇠 검사에 제 코드가 걸렸습니다

- **상황:** 만든 화면 파일에 **AI 열쇠 문자열이 섞여 들어갔는지** 검사했습니다
  (설계서 수용 기준에 있습니다).
- **증상:** **걸렸습니다.** 검사기가 화면 파일에서 열쇠 이름을 찾아냈습니다.
- **원인:** 진짜 열쇠가 아니었습니다. *"AI가 안 될 때 열쇠가 없어서인지 판별하는 코드"* 에
  열쇠 **이름**을 적어 뒀던 겁니다. 값이 아니라 이름이었습니다.
- **해결:** 그래도 뺐습니다. **이름이 남아 있으면 다음에 검사할 때 또 걸리고,
  그때는 "아 저건 괜찮은 거였지" 하고 넘어가게 됩니다.** 그렇게 넘어가는 습관이 들면
  진짜 유출이 났을 때도 넘어갑니다. 우리말 단어(「열쇠」)로 판별하게 바꿨습니다.
- **남은 문제:** 없습니다. 다시 검사해서 깨끗한 것을 확인했습니다.

## 🔀 갈림길에서 무엇을 왜 골랐나

### ① 전체 목록 — 섹션만? 토글까지?

사용자가 **판단을 저에게 맡기셨습니다.**

| | 고른 것 | 버린 것 |
|---|---|---|
| | **토글까지 + 급한 것만 펴 두기** | 섹션만 나누기 / 전부 접기 |

- **결정적 이유:** 나누기만 하면 **줄 수가 그대로**입니다. "복잡해 보인다"가 안 풀립니다.
  전부 접으면 오늘 볼 것을 보려고 매번 눌러야 합니다. 둘 다 아니어서 가운데를 잡았습니다.
- **치른 대가:** 어느 영역을 폈는지가 **화면을 새로 열 때마다 초기화**됩니다.
  기억하게 하려면 저장 공간이 하나 더 필요한데, 지금 그럴 값어치는 없다고 봤습니다.

### ② AI 모델 — 정해질 때까지 기다릴까?

| | 고른 것 | 버린 것 |
|---|---|---|
| | **임시로 정하고 진행** | 사용자 답을 기다림 |

- **결정적 이유:** 사용자가 **AI를 지금 써 보고 싶어 하셨습니다.** 모델명 하나 때문에
  전체를 멈추면 아무것도 못 써 봅니다. 그리고 모델명은 **코드가 아니라 설정에 있어서**
  나중에 바꿔도 코드를 안 고칩니다 — 되돌리기가 쉬운 결정입니다.
- **치른 대가:** 지금 정한 모델이 최선인지 확인 안 됐습니다. 써 보고 답이 이상하면
  설정 한 줄로 바꿉니다.

### ③ 한글(.hwp) 파일

| | 고른 것 | 버린 것 |
|---|---|---|
| | **"PDF로 저장해 주세요"로 안내** | 서버에서 변환해서 읽기 |

- **결정적 이유:** 한글 파일을 읽으려면 별도 프로그램이 필요해서 **브라우저만으로는 안 됩니다.**
  서버에서 하려면 파일이 한 번 더 밖으로 나갑니다 — 계약서·급여대장이 오갈 자리인데
  그 대가를 지금 치를 이유가 없습니다.
- **치른 대가:** 실무에서 한글 파일이 많으면 매번 PDF로 저장하는 손이 한 번 더 갑니다.
  **자주 걸리시면 다시 보겠습니다.**

### ④ 파일 글 뽑기 — 브라우저에서? 서버에서?

| | 고른 것 | 버린 것 |
|---|---|---|
| | **브라우저에서** | 서버에서 |

- **결정적 이유:** 서버에서 뽑으려면 **파일을 서버로 보내야 합니다.**
  브라우저에서 뽑으면 AI에게 보내기로 한 것만 나갑니다.
- **치른 대가:** 화면에 라이브러리가 두 개 늘었습니다(PDF·워드 읽기).
  대신 **실제로 그 파일을 올릴 때만** 내려받게 해서 평소 화면은 안 무거워집니다.

  어제 「진행 중 업무는 타임라인」 건처럼 모형에만 있는 결정이 또 있을 수 있습니다.
- ⚠️ **오늘 마감 표시가 색 없이 충분히 눈에 띄는지** 확인이 안 됐습니다. (이슈 2번)

### 일부러 안 한 것

- **엑셀 읽기** — 표를 글로 바꾸면 뜻이 뭉개집니다. 필요한 표를 복사해 「상세」에
  붙여 넣는 편이 정확합니다.
- **AI가 체크리스트를 저절로 담기** — 규칙상 **AI는 초안까지**입니다. 사람이 누릅니다.
- **여러 업무를 한꺼번에 AI에게 보여 주기** — 이 업무 하나에 붙은 것만 넘깁니다.
  *"이 건에 3주 썼다"* 가 엉뚱한 자리에서 새는 것을 막는 가장 단순한 방법입니다.
- **접어 둔 영역을 기억하기** — 갈림길 ① 참고.

| 주제 | 한 줄 |
|---|---|
| **실사용** | 설계서를 백 번 읽어도 안 나오는 것이 **한 번 써 보면** 나온다. 오늘 나온 요구 8개 중 설계서에 있던 건 0개 |

| **자동 계산** | 손으로 끄는 숫자는 근거가 없다. 3일만 지나면 본인도 그 숫자의 뜻을 모른다 |
| **두 곳을 다 열어 두지 않기** | 진행률을 체크리스트로도 정하고 손으로도 정하게 두면 **어느 쪽이 맞는지 알 수 없다.** 하나를 잠근다 |
| **접기** | 나누기만 하면 줄 수는 그대로다. **접어야 화면이 짧아진다.** 대신 전부 접으면 매번 눌러야 하니 급한 것만 펴 둔다 |
| **색의 예산** | 강조색은 예산이다. 다 쓰면 새로 만들 게 아니라 **다른 수단**(밝기·굵기·테두리·기둥)을 쓴다 |
| **다른 집에 사는 것** | 데이터베이스의 자동 삭제 규칙은 **보관소까지 안 닿는다.** 집이 둘이면 치우는 것도 둘이다 |
| **신뢰 경계** | 브라우저가 보낸 걸 그대로 믿으면 안 된다. 서버가 **다시 읽는다.** 조금 느려지는 값으로 안전을 산다 |
| **검사에 걸린 것을 그냥 넘기지 않기** | 가짜 경보라도 남겨 두면 다음에 또 걸리고, 그때는 진짜도 넘긴다 |
| **되돌리기 쉬운 결정은 미루지 않는다** | 모델명은 설정 한 줄이라 언제든 바꾼다. 그걸 기다리느라 전체를 멈출 이유가 없다 |
